Farm custom artwork folder

Preferred filenames:
- main-house.png
- rockhouse.png
- bob.png

The dashboard first looks for these files in /static/art1/.
If they are not present, it falls back to the three artwork PNGs currently stored directly in stockpi/static/.

Once the three preferred files are uploaded here and confirmed working, the old UUID-named fallback images in stockpi/static/ can be removed.
